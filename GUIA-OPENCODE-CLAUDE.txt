CAPÍTULO 01 — O que é OpenCode
🤔 O que é?
OpenCode é uma ferramenta de código aberto que roda direto no seu terminal (PowerShell). Ela usa Inteligência Artificial para ajudar você a programar, criar arquivos, corrigir bugs e automatizar tarefas — tudo por texto.
🔧 O que ela faz?
- ✅ Edita arquivos automaticamente
- ✅ Cria projetos do zero
- ✅ Corrige erros de código
- ✅ Explica o que cada comando faz
- ✅ Funciona offline (depois de instalada)
- ✅ Gratuita e open-source
💡 Em linguagem simples:
> "É como ter um programador sênior sentado ao seu lado, que lê e escreve código no seu computador, e você só precisa conversar com ele."

CAPÍTULO 02 — O que é Claude Code
🤔 O que é?
Claude Code é um assistente de IA criado pela Anthropic (a mesma empresa do Claude). Diferente do OpenCode, ele roda dentro do VS Code como uma extensão.
🆚 OpenCode vs Claude Code
Recurso  OpenCode  Claude Code
--------------------------------
Onde roda  Terminal (PowerShell)  VS Code
Precisa de API Key  Sim (qualquer provedor)  Sim (Anthropic)
Código aberto  ✅ Sim  ❌ Não
Instalação  npm global (simples)  Extensão VS Code
Ideal para  Automação e scripts  Programação visual
🤝 Eles trabalham juntos!
Você pode usar OpenCode no terminal para tarefas rápidas e Claude Code no VS Code para programar visualmente. Os dois se complementam.

CAPÍTULO 06 — Obter API Key
🔑 O que é uma API Key?
É uma senha especial que permite o OpenCode se conectar à Inteligência Artificial. Sem ela, nada funciona.
🎯 Qual provedor escolher?
Provedor  Preço  Qualidade
----------------------------
Anthropic (Claude)  Pago (créditos)  ⭐⭐⭐⭐⭐ Melhor para código
OpenAI (GPT)  Pago (créditos)  ⭐⭐⭐⭐ Excelente
OpenRouter  Vários modelos  ⭐⭐⭐⭐ Bom custo-benefício
📥 Passo a passo — OpenRouter (recomendado para iniciantes)
PASSO 1: Acesse
→ https://openrouter.ai/keys
PASSO 2: Crie sua conta
→ Pode usar email ou login Google/GitHub
PASSO 3: Adicione créditos
→ Depósito mínimo: $5 (≈ R$25)
→ Isso dura MUITO tempo para uso pessoal
PASSO 4: Gere sua API Key
→ Clique em "Create Key"
→ Copie a chave (começa com "sk-or-v1-...")
PASSO 5: Salve em local seguro!
→ Guarde em um arquivo .txt
→ NUNCA compartilhe sua chave
📥 Passo a passo — Anthropic (para Claude)
PASSO 1: Acesse
→ https://console.anthropic.com/
PASSO 2: Crie sua conta
→ Verifique seu email
PASSO 3: Vá em API Keys
→ https://console.anthropic.com/settings/keys
PASSO 4: Create Key
→ Dê um nome: "Meu OpenCode"
→ Copie a chave (começa com "sk-ant-...")
⚠️ ALERTA: NUNCA COMPARTILHE SUA CHAVE
> 🔴 Sua API Key é como uma senha de banco. Se alguém tiver ela, pode usar seu crédito. Nunca cole em chats, redes sociais ou repositórios públicos.

CAPÍTULO 07 — Configurar settings.json
📁 O arquivo mágico
O settings.json é onde o OpenCode guarda suas configurações. Ele fica na pasta:
Windows: C:\Users\SEU-NOME\.opencode\settings.json
🛠️ Criar a pasta e o arquivo
Abra o PowerShell e cole:
powershell
New-Item -ItemType Directory -Force -Path "$env:USERPROFILE\.opencode"
New-Item -ItemType File -Force -Path "$env:USERPROFILE\.opencode\settings.json"
📝 Conteúdo do settings.json
Abra o arquivo no VS Code ou bloco de notas e cole:
json
{
"model": "openrouter/anthropic/claude-3.5-sonnet",
"apiKey": "sk-or-v1-AQUI_VAI_SUA_CHAVE",
"temperature": 0.7,
"maxTokens": 4096,
"theme": "dark",
"language": "pt-BR",
"systemPrompt": "Você é um engenheiro de software sênior especializado em Next.js, TypeScript e React. Responda em português brasileiro."
}
⚙️ Explicação de cada campo
Campo  O que faz  Exemplo
---------------------------
model  Qual IA usar  openrouter/anthropic/claude-3.5-sonnet
apiKey  Sua chave secreta  sk-or-v1-...
temperature  Criatividade (0=robotico, 1=criativo)  0.7
maxTokens  Tamanho máximo da resposta  4096
theme  Tema visual  dark
language  Idioma das respostas  pt-BR
systemPrompt  Personalidade da IA  Texto descritivo

CAPÍTULO 10 — Erros comuns e soluções
🐛 ERRO 1: Comando não encontrado
❌ "opencode não é reconhecido como comando interno"
✅ Solução:
powershell
Verifique se npm está no PATH
npm list -g --depth=0
Reinstale
npm install -g @opencode-ai/cli
🐛 ERRO 2: Permissão negada
❌ "Error: EACCES: permission denied"
✅ Solução:
powershell
Execute PowerShell como Administrador
(Clique direito → Executar como administrador)
Depois instale novamente
npm install -g @opencode-ai/cli
🐛 ERRO 3: API Key inválida
❌ "Invalid API key" ou "401 Unauthorized"
✅ Solução:
1. Verifique se copiou a chave completa
2. Verifique se não tem espaços extras
3. Confirme se o modelo corresponde ao provedor
4. Verifique se tem créditos na conta
🐛 ERRO 4: settings.json não encontrado
❌ "Could not find settings file"
✅ Solução:
powershell
New-Item -ItemType Directory -Force -Path "$env:USERPROFILE\.opencode"
New-Item -ItemType File -Force -Path "$env:USERPROFILE\.opencode\settings.json"
Depois edite o arquivo com o conteúdo do CAPÍTULO 7
code "$env:USERPROFILE\.opencode\settings.json"
🐛 ERRO 5: Node.js não encontrado
❌ "Node.js is not installed"
✅ Solução:
1. Baixe Node.js em https://nodejs.org
2. Instale a versão LTS
3. Marque "Add to PATH"
4. Reinicie o PowerShell
🐛 ERRO 6: Erro de conexão
❌ "Connection timeout" ou "Network error"
✅ Solução:
1. Verifique sua conexão com internet
2. Alguns modelos precisam de VPN?
3. Tente um provedor diferente
4. Verifique se o site do provedor está online
🐛 ERRO 7: Modelo não encontrado
❌ "Model not found" ou "404"
✅ Solução:
json
// Verifique se o nome do modelo está correto
// Exemplo correto para OpenRouter:
"model": "openrouter/anthropic/claude-3.5-sonnet"
// Exemplo correto para Anthropic direto:
"model": "anthropic/claude-3-5-sonnet-20241022"
🐛 ERRO 8: Git não encontrado
❌ "Git is not installed"
✅ Solução:
1. Baixe Git em https://git-scm.com
2. Instale com as opções padrão
3. Reinicie o PowerShell
